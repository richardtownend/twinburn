# Twinburn

A retro low-poly pod-racing game for the browser, with a roguelike run structure and two engine levers.

Play: https://richardtownend.github.io/twinburn/

- Phone: drag the left and right levers.
- Meta Quest: open the link in the Quest browser, pick a zone in Practice and tap **Race in VR**. The triggers are the engine levers; with a trigger held fully, squeeze its grip for overdrive. VR motion (Calm / Full) and view (Cockpit / Chase) are in the settings.
