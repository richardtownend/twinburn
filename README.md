# Twinburn

A retro low-poly pod-racing game for the browser, with a roguelike run structure and two engine levers.

Play: https://richardtownend.github.io/twinburn/

- Phone: drag the left and right levers.
- Meta Quest: open the link in the Quest browser, pick a zone in Practice and tap **Race in VR**. By default you squeeze a grip to grab that lever and push your hand forward to open it (pull back to close; let go and it stays). A Triggers option is in the settings. VR motion (Calm / Full) and view (Cockpit / Chase) are in the settings.
